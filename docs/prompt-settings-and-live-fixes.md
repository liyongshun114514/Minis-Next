### 保存及兼容

- 用户覆盖存于 `minis-global/memory/PROMPTS.json`（Linux 挂载后 `/var/minis/memory/PROMPTS.json`），默认模板保留在代码和 `assets/prompt-catalog.json`。
- 默认无覆盖时按原文渲染；编辑后由实际生产调用点读取覆盖。恢复默认删除覆盖而非把默认复制为自定义。
- `{{slotN}}` 是运行时插槽，`{name}` 是身份替换位，默认中自带的 `{{result}}` 留给调度器。必须保留默认占位符及次数，可调整顺序；不递归展开动态值。
- 保存用同目录临时文件、fsync、rename；失败不截断旧文件、不发布新缓存。恢复默认删除失败也报告错误。
- 编辑器保存使用点击时快照；保存期间新输入仍为未保存。切换条目隔离状态，返回目录刷新“已编辑”标记。
- 内置 skill-creator 模板显式保存/恢复时同步已安装 `SKILL.md`；正常启动不会覆盖用户技能修改。用户自行导入的技能、实际记忆正文、子代理自定义指令仍属于各自用户数据，不复制为静态模板。
- 现有 memory 备份覆盖 PROMPTS.json，恢复后重新加载缓存。
- 已有 SOUL.md、工作区文件和聊天记录不迁移/不清空；iOS 参考实现、CLI --help、UI错误文案及构建期私有供应商标识不当作 Android 主提示词目录项。

校验：`python3 scripts/check-prompt-catalog.py` 检查唯一编号、默认文本、运行绑定、占位符以及源码位置；移动调用点后可用 `--refresh-sources` 只刷新位置。
