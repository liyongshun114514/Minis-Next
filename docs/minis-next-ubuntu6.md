# Minis Next 1.15-ubuntu.6

本轮范围：统一沿用“+ → 权限”的 Root 三态、chroot CLI 通信修复、思考滑块视觉、可调子代理并发及队列修复、自定义提示词 UI、余额渠道扩展。未引入多 Agent 协作模式。

## 权限与通信

- 所有需要真实 Root 的 chroot 命令（包括读取命令）仍经过同一三态入口；普通 App 权限读取及不执行进程的 status 查询维持只读行为。
- 升级时按 APK 内客户端内容校验并刷新 rootfs 中的 guest offload client，不再永久复用首次安装的旧版本。
- 刷新串行执行、原子替换；替换失败保留旧客户端。
- Root shell 保持 uid0；仅 IPC connect 临时使用 App 身份，服务端同 UID 检查保持有效。
- 对身份拒绝、坏帧、截断及过期 socket 给出可区分错误；真实 C 客户端使用 mock 服务进行字节协议回归。

## 子代理并发

设置 → 子代理新增“子代理并发数量”，每个父对话可选 1–8，默认 3，重启后恢复。现有代理定义不删除。

异步创建子会话前预留槽位，正式注册时接替；排队调度填满可用槽位，启动失败/取消释放预留；调高并发立即补位，调低不打断正在运行的任务。模型可见工具说明使用实际并发值。排队任务失败时写回失败结果，不永久留在排队状态。

## 界面

- 思考滑块整个胶囊铺满蓝紫渐变，前两档保留动态粒子与高光，原刻度/手势/释放动画继续使用。
- 全局提示词与自定义规则分别呈现；规则按分组/模型显示，提供目标、状态、摘要、编辑、删除与同范围排序；目标通过独立列表选择。

## 余额

新增 Novita AI、Vercel AI Gateway、LiteLLM Proxy 查询适配；余额缺失或无法解析时返回不支持/错误，不能显示伪造的零余额。LiteLLM 展示 key 的预算/消费，不能当成上游供应商钱包。

## 验证边界

完整编译、JUnit 回归、签名/包结构及生产 rootfs 解压由 GitHub Actions 执行。本机仅做必要静态、纯 Kotlin 与 C 协议检查。构建成功不代表已安装、实机视觉或真实 Root 运行通过。本轮不执行设备 Root、不安装 APK。
